zix WebRTC data channel file transfer

Pick a file and it goes up one data channel in 16 KB pieces. zix counts what arrives and sends the running total back down the same channel. Nothing is written to disk on either side.

Sending pauses whenever the browser's own send queue passes 1 MB and starts again once it has drained to 256 KB. That pause is the whole point of the example: a channel that is written to faster than the network drains it grows a queue in the browser, and the page is what has to notice.
